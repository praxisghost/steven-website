## Decision 004

Nodes should remain mostly stable.

Do not significantly rearrange node positions between updates.

Users should develop spatial memory.

## Decision 013

Three.js is vendored (self-hosted) at /vendor/three.module.min.js rather than
loaded from a CDN.

Rationale: the server's Content-Security-Policy allows scripts only from 'self'
(plus Google Translate), and the site deliberately avoids third-party requests
for GDPR reasons. A CDN would be blocked and would violate the site's privacy
posture. The page imports Three.js as an ES module under the existing CSP with
no server changes.

Status: Accepted

---

## Decision 014

Graph data is generated by a build script (tools/graph/build-graph.mjs) into a
static JSON file (public/isms/superorganism-graph.json), not computed in the
browser at load time.

Rationale: page discovery requires filesystem access; precomputing keeps the
client fast and lets node positions be stored and reused for stability.
The script must be re-run whenever pages are added.

Status: Accepted

---

## Decision 015

Connections use a conservative hub-and-spoke model: each page connects to its
category hub, hubs connect to the site centre (index.html), plus a small
curated set of semantic edges. No full meshes, no automatic dense linking.

Rationale: implements the Connection Philosophy (Decisions 007/008) concretely.
Result is ~1.18 edges/node — sparse, readable, Obsidian-like.

Status: Accepted

---

## Decision 016

The graph is rendered in 2D using an OrthographicCamera (a flat "star map"),
not a 3D scene.

Rationale: the ObsidianExample reference images are 2D; a flat map maximises
readability, gives predictable pan/zoom, and keeps spatial memory intact.

Status: Accepted

---

## Decision 017

Node positions are deterministic (category sectors + golden-angle spiral seeded
by a stable hash of the page path) AND previous positions are reused on every
rebuild. New pages get a computed position; existing pages keep theirs.

Rationale: satisfies Decision 004 (stable positions / spatial memory) even as
pages are added over time.

Status: Accepted
