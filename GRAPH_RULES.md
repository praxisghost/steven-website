# GRAPH_RULES.md

## Mission

Build and continuously improve the Superorganism knowledge graph.

The graph should function as:

* navigation system
* discovery tool
* visual representation of site knowledge

---

## Requirements

1. Preserve existing functionality.

2. Never break navigation.

3. Never remove nodes without explicit reason.

4. Prefer incremental improvements.

5. Document all work.

6. Update GRAPH_PROGRESS.md after every session.

7. Update GRAPH_DECISIONS.md whenever a major decision is made.

8. Update GRAPH_BACKLOG.md whenever tasks are completed.

9. Preserve visual consistency.

10. Reference ObsidianExample images regularly.

---

## Visual Goal

Emulate the feeling of Obsidian Graph View:

* dark background
* minimal design
* smooth interactions
* information density
* exploratory navigation

without cloning Obsidian.

---

## Connection Philosophy

Connections should be:

* meaningful
* sparse
* useful

Avoid:

* clutter
* over-linking
* random associations

---

## Long-Term Goal

Create a living map of the website.

Every page eventually becomes part of a single interconnected visual knowledge system.
