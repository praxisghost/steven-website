# Graph Visual Specification

Graph Page

Writing → -isms → Superorganism

Reference Images

/ObsidianExample/

Visual Goal

Recreate the overall visual feeling of Obsidian Graph View.

Observations From Reference Images

1. Nodes are tiny.

2. Nodes are mostly grey.

3. Connections are subtle.

4. Labels appear primarily during interaction.

5. Large amounts of negative space exist.

6. Graph readability is prioritized.

7. Graph movement is minimal.

8. The graph resembles a star map.

9. The graph feels calm and organized.

10. The graph supports large collections of information.

Desired User Experience

The user should feel like they are exploring a map of the website.

Every page should feel like a location.

The website should feel like a living interconnected superorganism.

The graph should prioritize discovery and navigation over visual spectacle.

Three.js should be used to create a smooth and scalable experience.

1,000+ pages
