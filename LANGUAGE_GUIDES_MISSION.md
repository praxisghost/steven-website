# LANGUAGE_GUIDES_MISSION.md

## Objective

Expand the language-guide system so that every language offered as a target language from English eventually becomes available as a target language from every other supported source language.

Never create a guide for learning English.

English is the reference language only.

---

## Existing Source Material

Use existing high-quality guides as structural references.

Examples:

* Cantonese Learning Guide
* German Learning Guide
* Spanish Learning Guide

Study these guides before creating new ones.

Match their:

* depth
* organization
* formatting
* educational quality
* navigation structure

Do not create filler content.

---

## Required Quality Standard

Every guide must be a genuinely useful language-learning resource.

Every guide must contain:

### 1. Overview

* language family
* where spoken
* number of speakers
* major dialects
* writing systems

### 2. Pronunciation

* phonology overview
* difficult sounds
* pronunciation tips

### 3. Writing System

If applicable:

* alphabet
* syllabary
* abjad
* abugida
* logographic system

Include examples.

### 4. Grammar Guide

Cover major grammar topics.

Examples:

* word order
* tense
* aspect
* mood
* particles
* case systems
* classifiers
* agreement
* gender systems
* honorific systems

Explain concepts from the perspective of the learner's native language.

### 5. Core Vocabulary

Minimum:

100 vocabulary terms

Preferred:

150-300 terms

Organize by topic.

Examples:

* greetings
* family
* food
* travel
* numbers
* colors
* verbs
* adjectives

### 6. Example Sentences

Minimum:

25 sentences

Must include:

* source language
* target language

### 7. SRS Section

Every vocabulary item must be convertible into flashcards.

Format:

Front:
Target Language

Back:
Source Language

### 8. Learning Strategy

Explain:

* what is difficult
* what is easy
* common mistakes
* recommended study sequence

### 9. Resource Section

Must contain real resources.

Examples:

* dictionaries
* grammar references
* podcasts
* YouTube channels
* textbooks
* online courses
* readers

Do not invent resources.

Use reputable resources.

---

## Guide Generation Strategy

English-language guides are considered master templates.

When creating:

Japanese → German

Study:

English → German

and

English → Japanese

Use both as reference material.

Adapt explanations for Japanese-speaking learners.

Do not simply translate English guides.

Rewrite explanations from the perspective of the learner's native language.

---

## Navigation Requirements

New guides must:

* appear in navigation
* appear in language listings
* be linked correctly
* be searchable

---

## Accuracy Requirements

Never invent:

* grammar
* vocabulary
* pronunciations
* writing systems

Only include verified linguistic information.

---

## Scale Requirements

The long-term objective is a complete language-guide network.

If:

Language A exists

and

Language B exists

then eventually:

A → B

should exist.

Exception:

No guide may target English.

---

## Per Run Limits

Maximum:

1 guide per run.

Never create multiple guides in one execution.

Focus on quality over quantity.

---

## Completion Requirements

After creating a guide:

1. Update LANGUAGE_GUIDES_PROGRESS.md
2. Update CHANGELOG.md
3. Recommend the next guide
4. Stop
