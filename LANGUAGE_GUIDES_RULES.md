# Language Guide Rules

## Goal

Create comprehensive language-learning guides.

## One Guide Per Run

Maximum:

1 language guide

per execution.

Never create multiple guides in a single run.

---

## Quality Standard

Each guide must:

* Resemble the Cantonese guide
* Resemble the German guide
* Resemble the Spanish guide

Maintain similar depth and structure.

---

## Required Sections

1. Overview
2. Pronunciation
3. Writing System
4. Core Grammar
5. Sentence Structure
6. Common Mistakes
7. Learning Strategy
8. Resource Recommendations
9. Vocabulary List
10. SRS Flashcard Data

---

## Vocabulary Requirement

Minimum:

100 vocabulary terms

Preferred:

150–300 terms

Group by topic.

---

## Accuracy Requirement

Never invent grammar.

Never invent vocabulary.

Never invent pronunciation.

Use authoritative language-learning sources.

---

## Resource Requirement

Include:

* Dictionaries
* Grammar resources
* YouTube channels
* Podcasts
* Courses
* Textbooks

Only reputable sources.

---

## Progress Tracking

After completion:

Update:

LANGUAGE_GUIDES_PROGRESS.md

and

CHANGELOG.md

Then stop.
