# LANGUAGE_VOCAB_RULES.md

## Mission

Expand vocabulary databases across all language guides.

Create downloadable vocabulary exports.

Improve Anki compatibility.

Improve language-learning utility.

---

## Rules

1. Never delete vocabulary.

2. Never duplicate vocabulary.

3. Preserve existing formatting.

4. Preserve existing table structures.

5. Use UTF-8 encoding.

6. Use reliable sources only.

7. Add source citations internally where possible.

8. Prefer common vocabulary first.

9. Respect existing page design.

10. Maintain consistency across guides.

---

## Export Requirements

Each guide should eventually include:

Download Vocabulary CSV

or

Download Vocabulary Markdown

at the bottom of the final vocabulary section.

---

## CSV Requirements

UTF-8 encoding.

Compatible with:

* Anki
* Excel
* LibreOffice
* Google Sheets

---

## Anki Requirements

Vocabulary columns should map directly to Anki fields.

---

## Incremental Development

Each execution should:

1. Expand vocabulary.
2. Update export files.
3. Verify no duplicates.
4. Record progress.
