# Chicago Citation Standards

## Footnote Format

Author First Last, "Page Title," Website Name, publication date if available, accessed Month Day, Year, URL.

Example:

1. John Smith, "History of Swahili," Example Linguistics Institute, accessed June 1, 2026, https://example.org/history-of-swahili.

## Bibliography Format

Smith, John.

"History of Swahili."

Example Linguistics Institute.

Accessed June 1, 2026.

https://example.org/history-of-swahili.

## Requirements

* Use Chicago Notes and Bibliography style.
* Include working URLs.
* Include author when available.
* Include publication date when available.
* Include access date when publication date is unavailable.
* Never fabricate metadata.
* Never fabricate authors.
* Never fabricate publication dates.
