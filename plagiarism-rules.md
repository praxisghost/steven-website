# Plagiarism Detection Rules

## Conservative Policy

Only make changes when evidence is strong.

False positives are unacceptable.

## High Confidence Indicators

Examples:

* Exact sentence matches
* Nearly identical paragraph structure
* Unique wording that appears on a source page
* Specialized phrasing unlikely to be independently written

## Not Plagiarism

Do not modify:

* Common facts
* Language names
* Country names
* Grammar terminology
* Definitions written in generic language
* Standard educational explanations
* Widely used linguistic terminology

## Citation Threshold

A citation should only be added if:

1. A source is identified.
2. Content clearly derives from that source.
3. Attribution improves academic integrity.

## Rewrite Rules

When remediation is required:

* Preserve meaning.
* Change sentence structure.
* Change wording.
* Avoid synonym swapping only.
* Produce genuinely original phrasing.

## Human Review

Flag content if:

* Source uncertainty exists.
* Multiple possible sources exist.
* Attribution is unclear.
* Extensive rewriting would be required.
