Workshop 1 of 2 — Getting Set Up & Your First Cards

90 minutes · Covers: why spaced repetition works, initial setup, FSRS, note types, & creating your first cards.

1. Why Anki Works

Anki is a flashcard app built around spaced repetition — a technique that shows you a piece of information just before you're likely to forget it. Instead of cramming, you review at growing intervals, & each successful recall makes the memory last even longer.

2. Getting Started

Checklist

  • Download Anki from apps.ankiweb.net
  • Create an account with your email & verify it
  • Sign in on your computer — & on your phone if you have it

3. Tweaking Settings for Best Results

Anki's defaults are fine, but a few changes make a big difference. Open Preferences (Anki → Preferences) & your Deck Options to apply these before you add your first card.

3a · Enable FSRS (Free Spaced Repetition Scheduler)

FSRS is a modern algorithm that outperforms Anki's original SM-2 scheduler. It builds a personalised memory model for each card.

  1. Go to Tools → Preferences → Review tab
  2. Turn on FSRS — this enables the smarter scheduler
  3. Set Desired retention to 0.90 (90%) — a good balance between workload & recall
  4. Click Optimise after you've built up at least a few hundred reviews to personalise the model to you
3b · Deck Preset Settings

Go to a deck → Options (gear icon). These settings apply to all decks using that preset. Keep new cards per day manageable — starting at 10–20 per day is recommended for most learners.

4. Install Review Heatmap

Review Heatmap adds a GitHub-style activity chart to your home screen so you can see your review streaks at a glance.

  1. Open Tools → Add-ons → Get Add-ons
  2. Enter code 1771074083
  3. Click OK & wait for the download to finish
  4. Restart Anki — the heatmap appears on your main screen automatically

5. Notes, Cards & Note Types

The most important concept to grasp: in Anki you don't create cards directly — you create notes, & Anki generates one or more cards from each note automatically.

What is a Note Type?

A note type is a reusable template that defines:

  • Which fields exist (e.g. Word, Translation, Audio, Example Sentence)
  • How those fields are used to generate card templates

Change a note type, & every note using it updates automatically.

6. Creating Your Note Type

6a · Add a new note type
  1. Open Tools → Manage Note Types
  2. Click Add → choose Add: Basic → name it, e.g. Language Vocab
  3. Click Fields & set up your fields (see suggestions below)
  4. Click Cards to design your card templates
6b · Suggested fields
FieldPurpose
WordThe target-language word or phrase
TranslationYour native-language meaning
AudioPronunciation sound file (auto-filled by HyperTTS in Workshop 2)
Example SentenceAn in-context example in the target language
NotesGender, register, grammar notes, or memory hooks
6c · Suggested card templates
  • Template 1 — Recognition: Word → Translation + Audio + Example
  • Template 2 — Recall: Translation → Word + Audio
  • Template 3 — Listening: Audio only → Word + Translation

Starting with Templates 1 & 2 is sufficient for most learners. Add Template 3 once you have audio in your deck.

7. Adding Your First Note

  1. From the main screen click Add (or press A)
  2. Make sure the Note Type at the top shows your new type
  3. Fill in each field: Word, Translation, Example Sentence, Notes
  4. Leave Audio blank for now — we'll fill it automatically in Workshop 2
  5. Click Add — you've created your first note!
  6. Add two or three more notes so you have something to review
  7. Click Study Now on your deck & do your first review session

Workshop 2 of 2 — Audio, Card Styling & AI-Generated Cards

90 minutes · Covers: HyperTTS automatic audio, card HTML/CSS styling, & generating card batches with AI tools.

1. HyperTTS — Automatic Audio

HyperTTS is an Anki add-on that uses text-to-speech (or real recordings where available) to fill your Audio field automatically for entire decks — no manual recording needed.

1a · Install HyperTTS
  1. In Anki: Tools → Add-ons → Get Add-ons
  2. Enter code 1508862472
  3. Click OK & restart Anki
1b · Create a free AwesomeTTS Cloud account

HyperTTS connects to the AwesomeTTS Cloud service for high-quality voices. You get a free tier with plenty of monthly characters.

  1. Go to app.hypertts.io & create a free account
  2. Copy your API key from the dashboard
1c · Connect HyperTTS to your account
  1. In Anki: HyperTTS → Settings
  2. Paste your API key into the AwesomeTTS API Key field
  3. Click Verify — you should see your account status & character balance
1d · Add audio to your deck
  1. Select your deck in the main screen
  2. Click HyperTTS → Add Audio to Deck
  3. Source field: Word (or whichever field has the target-language text)
  4. Target field: Audio
  5. Choose a voice — pick a native speaker voice for your target language
  6. Click Preview on a sample card to check the quality
  7. Click Add Audio — HyperTTS fills the Audio field for every note in the deck

2. Styling Your Cards

Card styling lives inside your note type's card templates. You write standard HTML for the layout & CSS for the appearance. Open: Tools → Manage Note Types → [your type] → Cards

2a · The three panes
PaneWhat to put here
Front TemplateHTML that renders the front of the card (the question)
Back TemplateHTML that renders the back (includes the front via {{FrontSide}})
Styling (CSS)CSS rules that apply to both sides of all cards in this note type
2b · A clean starter template

Front Template:

{{Word}}
{{Audio}}

Back Template:

{{FrontSide}}
<hr id=answer>
<div class="translation">{{Translation}}</div>
<div class="example">{{Example Sentence}}</div>
<div class="notes">{{Notes}}</div>

Styling (CSS):

.card { font-family: sans-serif; font-size: 20px; text-align: center; color: #fff; background: #1a1a1a; }
.translation { color: #7eb8f7; margin-top: 0.5em; }
.example { color: #aaa; font-style: italic; margin-top: 0.5em; font-size: 0.85em; }
.notes { color: #666; font-size: 0.75em; margin-top: 0.5em; }

3. Creating Cards with AI

AI tools (DeepSeek, ChatGPT, Claude) can generate ready-to-import card lists in seconds. You paste a prompt, get a spreadsheet-style list back, & import it straight into Anki.

3a · The basic approach
  1. Write a prompt that specifies your fields & format (see examples below)
  2. Paste the AI's output into a plain text file or Google Sheets
  3. In Anki: File → Import
  4. Match each column to the correct field in your note type
  5. Click Import — your cards appear instantly
3b · Sample prompt for vocabulary cards

Paste this prompt (adapt the language & topic as needed):

Generate 20 German vocabulary flashcard entries for household items.
Output as tab-separated values with no header row.
Columns in this exact order: German word, English translation, example sentence in German, grammar notes (gender/plural).
No markdown formatting, no asterisks, no backticks.
3c · Tips for better AI output
  • Always ask for no header row & specify the exact separator (tab is most reliable)
  • For languages with gendered nouns, ask for gender in the Notes column
  • Ask for no markdown formatting — asterisks & backticks break the import
  • Generate in batches of 20–30 rather than 100+ to keep quality consistent
  • Always spot-check a sample before running HyperTTS on the whole batch
