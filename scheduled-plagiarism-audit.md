# Scheduled Task: Website Plagiarism Audit and Remediation

You are performing a recurring plagiarism audit on this website.

## Goal

Review content pages and identify any text that appears to be copied or very closely paraphrased from external sources.

This task must proceed incrementally.

Each execution should process only a limited batch of pages so work can be reviewed safely.

## Scope

Audit only content pages.

Do NOT audit:

* Home page
* Navigation pages
* Language index pages
* Search pages
* Category hubs
* Sitemap pages
* Administrative pages
* Footer content
* Header navigation

Focus on pages containing educational, historical, linguistic, grammatical, vocabulary, cultural, or reference content.

## Batch Size

Process:

* 3–10 pages per execution

Update progress tracking after completion.

## Workflow

For each page:

### Step 1: Scan

Review all content.

Identify text that appears potentially copied from:

* Books
* Dictionaries
* Encyclopedias
* Academic sources
* Educational websites
* Government websites

### Step 2: Verify

Before making changes:

Search for exact wording.

Only proceed if there is strong evidence that wording originates from a specific source.

Confidence must be HIGH.

If confidence is MEDIUM or LOW:

Leave the text unchanged.

### Step 3: Remediate

If plagiarism is verified:

* Rewrite the passage using original wording.
* Preserve meaning.
* Preserve factual accuracy.
* Preserve reading level.

Do not dramatically expand content.

Do not remove useful information.

### Step 4: Citation

Add a Chicago-style footnote only when:

* A source is clearly identified.
* The information materially derives from that source.

Do not add unnecessary citations.

Do not cite common knowledge.

### Step 5: Bibliography

If a page receives one or more footnotes:

Create or update a bibliography section at the bottom.

Requirements:

* Chicago style.
* Real source title.
* Real author if available.
* Real publication information if available.
* Real URL.

Never invent citation data.

### Step 6: Report

Generate a report containing:

* Pages reviewed
* Pages modified
* Sources added
* Number of footnotes added
* Any pages requiring human review

Update progress log.
